# 前端开发工程师

## 岗位JD
- 负责 Web 前端页面、组件和交互流程的设计与实现，保障产品体验一致性和交付效率。
- 与产品、设计、后端协作，完成需求澄清、方案评审、开发联调和上线验收。
- 持续优化前端性能、可维护性和工程质量，包括构建效率、组件复用、状态管理和监控埋点。
- 关注复杂交互场景中的稳定性问题，例如白屏、首屏加载慢、状态错乱、跨端兼容等。

## 必备技能
- 熟悉 HTML、CSS、JavaScript/TypeScript，能独立完成中后台或业务页面开发。
- 熟悉 React、Vue 等主流框架中的组件拆分、状态管理、生命周期和性能优化。
- 理解接口联调、异常处理、权限控制、路由管理、表单校验和常见前端工程化能力。
- 能说明首屏性能、资源加载、打包优化、懒加载、缓存策略和浏览器渲染机制。
- 具备良好的协作与抽象能力，能推动设计系统、组件库或前端规范沉淀。

## 常见面试题
1. 讲一个你主导过的前端项目，重点说明页面复杂度、状态管理方式和你的核心贡献。
2. 你做过哪些性能优化？请结合具体指标说明问题、方案和最终效果。
3. 当页面状态复杂、接口多、交互链路长时，你如何拆组件和组织数据流？
4. 如果线上出现白屏、接口成功但页面不更新、用户反馈卡顿，你会如何排查？
5. 在一个需要频繁迭代的业务里，你如何平衡开发效率、代码质量和组件复用？

## 重点考察维度
- 是否具备清晰的组件设计和状态管理思路，而不是只会堆页面逻辑。
- 是否真正理解前端性能与体验优化，能讲出指标、工具和定位方式。
- 是否有工程化意识，能谈到目录组织、复用、规范、测试或埋点监控。
- 是否能在复杂交互中体现问题拆解能力、边界处理能力和协作推进能力。
- 是否能把用户体验改进、业务转化或研发效率提升讲成有结果的案例。
