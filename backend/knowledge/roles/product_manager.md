# 产品经理

## 岗位JD
- 负责业务需求洞察、方案设计、优先级判断和项目推进，对产品目标和业务结果负责。
- 通过用户调研、数据分析、竞品分析和业务协作，持续发现问题并推动产品迭代。
- 输出需求文档、流程图、原型和指标方案，协调研发、设计、运营、销售等多角色落地。
- 跟进上线效果，围绕转化率、留存、使用率、效率等核心指标持续优化产品方案。

## 必备技能
- 具备结构化需求分析能力，能把模糊问题拆成目标、用户、场景、约束和方案。
- 熟悉原型设计、需求文档、流程梳理和项目推进，能在跨团队协作中推动事项落地。
- 理解数据指标与业务目标的关系，能设计核心指标并根据数据做迭代判断。
- 能平衡用户价值、商业价值、实现成本和交付节奏，做出合理优先级排序。
- 具备良好的表达与推动能力，能在分歧场景下达成共识并推进结果。

## 常见面试题
1. 讲一个你主导过的产品迭代，说明问题来源、目标用户、核心方案、推进过程和结果。
2. 当多个需求同时排队时，你如何判断优先级？请举一个真实例子说明。
3. 你如何定义一个功能是否成功？会关注哪些指标，如何验证结果？
4. 如果研发、设计、业务方对方案意见不一致，你会如何推动项目继续前进？
5. 遇到上线后效果不达预期的功能，你会如何判断是需求问题、执行问题还是时机问题？

## 重点考察维度
- 是否具备从问题到方案再到结果的完整闭环表达能力，而不是只讲执行动作。
- 是否真正理解用户、场景、业务目标与指标之间的关系。
- 是否能做优先级判断和方案取舍，并清楚说明判断依据。
- 是否具备跨团队推动能力，能处理分歧、资源受限和交付压力。
- 是否能对结果负责，包含上线后复盘、指标分析和后续优化动作。
