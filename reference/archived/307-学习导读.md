#### 路线 A · 读懂项目

这条路线以现有成品和配套文档为核心，先理清产品定位、V1迭代至V2的设计原因，以及开发过程中的核心难点

1. 了解项目全景与技术选型

👉🏻 [项目全景](https://acn2lw4rwc26.feishu.cn/wiki/JURmw18uGikxndkYl09ct0TWnA7)、[技术选型决策](https://acn2lw4rwc26.feishu.cn/wiki/Zpr8wlC8qifA7skN6dMcekwentg)

明确产品要解决的业务痛点、用户完整操作流程，理解各项技术方案背后的取舍逻辑。

2. 本地跑起来

👉🏻 [牛面Offer-面试智能体](https://acn2lw4rwc26.feishu.cn/wiki/M3KvwzMfTiken6kDF2scn4aenxf)（启动方式见项目 README.md）

跑通完整面试路径：注册账号 →上传简历 → 配置面试参数 → 生成并确认面试方案 → 开启模拟面试 → 流式实时对话 → 面试结束 → 查看完整评估报告 → 回看历史面试记录。

3. 拆解 V1 版本

👉🏻 [V1 版本开发](https://acn2lw4rwc26.feishu.cn/wiki/L49AwMwwgi2oAokG8ZHcJnmbnpd)

弄懂项目从零搭建、打通基础流程的完整思路，吃透LangGraph、流式输出、双分支执行、单元测试等底层工程能力。

4. 拆解 V2 版本

👉🏻 [V2 版本优化](https://acn2lw4rwc26.feishu.cn/wiki/YcCQwE3L4ie1ngkUf0qcdr80nbf)

梳理版本升级的核心诉求，理清新增能力带来的开发难点与解决方案。

5. 求职收尾

👉🏻 [常见面试问题](https://acn2lw4rwc26.feishu.cn/wiki/FiLBwNwLUiWigIknkQncwELenib)、[简历写法](https://acn2lw4rwc26.feishu.cn/wiki/M4gCw4kb3iWLW1kWRw7cf1XjnRe)

基于本项目素材打磨简历、准备面试问答。

#### 路线 B · 动手实战

不用现成完整代码，靠 AI 一步步做出面试智能体。
