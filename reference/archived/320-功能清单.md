#### 面试管理模块

|  |  |  |
| --- | --- | --- |
|  |  |  |
|  |  |  |
| 确认开始面试（activate） | 用户确认后将会话状态从 preparing 切换为 active，进入正式面试。仅 preparing 状态的会话可调用此接口。 | 注册用户 |
| 提交回答（reply） | 用户提交当前题目的回答，系统通过 interview_graph 判断是否追问。若需追问且该题追问未完成，返回追问内容；否则推进到下一题。AI 回复通过 SSE 流式输出。仅 active 状态的会话可调用。 | 注册用户 |
| 追问逻辑 | 每道题最多追问一次，由 QuestionThread 的 follow_up_done 标志控制。追问完成后自动进入下一题。 | 系统（interview_graph） |
| 触发评分（evaluate） | 4道题全部完成后可触发，调用 evaluation_graph 对整场面试打分，结果通过 SSE 流式输出，完成后写入 evaluation_json 字段，会话置为 completed。 | 注册用户 |
| 结束面试（finish） | 显式结束面试，将会话置为 completed，若评分未生成则不写入评分数据。用于用户中途放弃的场景。 | 注册用户 |
| 面试列表 | 返回当前用户的所有面试会话，含状态、难度、创建时间和关联简历名称，按创建时间倒序。 | 注册用户 |
| 查看面试详情 | 返回指定会话的完整信息，包含所有消息记录和评分报告（如已完成评分）。 | 注册用户 |
| 配额查询 | 在用户信息接口（GET /api/auth/me）中返回 quota_remaining 字段，前端据此控制创建面试的按钮状态。 | 注册用户 |

#### 评分报告模块

| 功能名称 | 描述 | 涉及角色 |
| --- | --- | --- |
| 生成评分报告 | evaluation_graph 对4道题的全部对话内容进行分析，从技术深度、表达清晰度、项目经验匹配度等维度打分，生成总体评价和改进建议。 | 系统（evaluation_graph） |
| 查看评分报告 | 在 evaluation 视图展示结构化报告，包含各维度评分和文字说明。仅 completed 状态的会话有评分报告。 | 注册用户 |
| 报告持久化 | 评分结果存入 interview_sessions 表的 evaluation_json 字段，永久可查，不依赖会话缓存。 | 系统 |

#### 用户认证模块

| 功能名称 | 描述 | 涉及角色 |
| --- | --- | --- |
| 注册 | 用户名和密码注册，用户名唯一，密码 bcrypt 哈希存储，初始配额5次。用户名已存在时返回 USERNAME_EXISTS 错误。 | 游客 |
| 登录 | 用户名密码登录，验证通过后返回 JWT Token，Token 有效期12小时。凭据错误时返回 INVALID_CREDENTIALS 错误。 | 游客 |
| 获取当前用户信息 | 返回登录用户的用户名、配额剩余量和注册时间。需携带有效 Token。 | 注册用户 |
| Token 鉴权 | 所有需要登录的接口通过 JWT 中间件验证 Authorization header，Token 无效或过期时返回 401。 | 系统 |
