#### users 表

存储注册用户的账户信息和使用配额。

|  |  |  |  |
| --- | --- | --- | --- |
|  |  |  |  |
| username | TEXT | 是 | 用户名，全局唯一，长度 3-32 字符，用于登录 |
| password_hash | TEXT | 是 | bcrypt 哈希后的密码，原始密码不存储 |
| quota_remaining | INTEGER | 是 | 剩余面试配额，初始值为 5，每次发起面试时原子扣减1，最小值为 0 |
| created_at | TEXT | 是 | 账户创建时间，ISO 8601 格式，UTC 时区，示例：2024-01-15T08:00:00Z |

说明： quota_remaining 的扣减使用两步操作：先 SELECT 检查配额是否充足，再执行 UPDATE。

#### resumes 表

存储用户上传的简历文件解析后的结构化信息。

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | 是 | 主键，自增 |
| user_id | INTEGER | 是 | 外键，关联 users.id |
| filename | TEXT | 是 | 原始文件名，含扩展名，示例：张三_后端开发_2024.pdf |
| payload_json | TEXT | 是 | LLM 解析后的结构化简历，JSON 字符串。结构见下方说明 |
| created_at | TEXT | 是 | 上传时间，ISO 8601 格式，UTC 时区 |

|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

| updated_at | TEXT | 是 | 最后更新时间，状态变更时自动更新，ISO 8601 格式，UTC 时区 |

#### messages 表

存储面试会话中的每一条消息，是面试对话的完整记录。

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | 是 | 主键，UUID 字符串 |
| session_id | TEXT | 是 | 外键，关联 interview_sessions.id |
| seq | INTEGER | 是 | 消息序号，同一会话内从1递增，用于排序 |
| role | TEXT | 是 | 消息角色，枚举值：user、assistant。 |
| kind | TEXT | 是 | 消息类型，枚举值：question、answer、follow_up、follow_up_answer |
| content | TEXT | 是 | 消息正文，纯文本。AI 回复在流式输出完成后整体写入，不分块存储 |
| created_at | TEXT | 是 | 消息创建时间，ISO 8601 格式，UTC 时区 |

说明： messages 表是持久化的完整对话记录，供历史查看使用；workflow_state_json 里的 question_threads 是 LangGraph 运行时的上下文，供 LLM 推理使用。两者在面试结束后保持一致，运行过程中以 workflow_state_json 为准。
