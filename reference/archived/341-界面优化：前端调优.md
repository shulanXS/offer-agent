界面视觉这块是前端一点点反复调试打磨出来的。这些细节面试很少考，但做产品的时候特别关键，一套成熟完整的 Agent 产品，不光功能要能用，整体使用体验也得跟上。下面跟大家分享下，没有设计稿的情况下，前端怎么把页面视觉效果优化到位。

#### 先做逻辑，后做界面

AI 对确定性的逻辑很擅长，给它接口定义和数据结构，它能生成功能完整的页面代码。但 AI 没有审美，自动生成的页面布局和视觉效果大概率是能凑合用，谈不上好看。

一个常见的错误是在逻辑还没稳定的时候就开始调界面。这样做有两个问题：

1. 没有真实数据就没有参考。 你调整一个评估报告页的布局，结果评分数据是假的、维度是占位符，调出来的效果和真实数据填充进去之后差距很大。

2. 逻辑变动会带来大幅界面调整。 面试 Agent 的记忆结构改了，评估报告页的证据引用展示可能要整体重排。你提前花在界面上的功夫，有可能因为一次后端调整全部白费。

所以 V2 的实际顺序是：先按专题文档把逻辑全部跑通，有真实数据可以渲染，再统一做界面优化。

#### 大布局：先截图给 ChatGPT 重新设计

先说整体页面布局怎么优化：先截页面图丢给ChatGPT重新规划版式。

等功能逻辑全部调通后，截图发给 ChatGPT 重新设计整套布局。

为啥要先截图再设计？基于真实页面给出的改版方案，会比纯文字描述需求靠谱得多。要是只靠文字讲需求，AI设计出来的结构很容易和现有代码脱节，到时候还要大规模改代码，得不偿失。

发截图的时候顺带附上简单调整方向就行，举个例子：

````
这是一个面试评估报告页，目前布局太平，层次感不强。
希望重新设计：整体风格偏专业简洁，配色参考深蓝主色调。
````

ChatGPT会输出新版布局方案，你确认方案没问题后，再把这份设计思路和现有页面代码一起交给AI，让它照着新布局重构页面。

#### 局部优化：用提示词描述调整

大布局定下来之后，局部的细节调整用自然语言描述给 AI：

````
分数颜色按档位区分：40分以下用红色，40到70用橙色，70以上用绿色。
证据引用默认折叠，点击展开。
未验证状态的维度行用灰色字体显示，不展示分数。
````

这类调整 AI 能很好地理解和执行，每次改一到两处，跑起来看效果，确认后再继续。不要一次描述太多改动点，容易改乱。

交互逻辑类的调整也用同样的方式：

````
选择简历之前，右侧配置区所有表单禁用，显示"请先选择简历"的灰色提示文字。
选中简历后配置区恢复可用。
````

#### 细节调优：直接用开发者工具

靠改提示词调细节有个短板：AI 很难精准 get 到微小的视觉差距。比如你说按钮间距太挤，它改完内边距，页面看着还是不对劲，来回沟通好几次都达不到想要的效果。

遇到这种情况最高效的办法，就是自己打开 Chrome 调试工具操作。选中要调整的元素，在样式面板直接改 CSS 参数，页面能实时看到变化，调到满意数值后，直接在项目文件里搜样式类名，手动修改。比反复跟 AI 描述 “再窄一点、往左挪一点” 省事太多。
