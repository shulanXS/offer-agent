#### 后端起不来或健康检查失败

现象： 运行 ./start.sh 报错退出；访问 [http://localhost:8000/healthz](http://localhost:8000/healthz) 无响应；提示 8000 端口被占用。

说明： 后端是 FastAPI 服务，默认监听 8000 端口。

排查：

1. 在 backend/ 下激活虚拟环境，执行 ./start.sh

2. 确认有 backend/.env（可从 .env.example 复制）

3. 端口占用：lsof -i :8000，有进程则关掉或换端口

4. 依赖不全：pip install -r requirements.txt

#### 前端白屏或接口 404

现象： 打开 [http://localhost:5173](http://localhost:5173) 页面空白；请求 /api/... 返回 404。

说明： 本地开发时，前端（5173）会把 /api 代理到后端（8000）。前端没起或代理没配好就会 404。

排查：

1. 在 frontend/ 执行 npm install 和 npm run dev

2. 本地一般不需要 frontend/.env，保持默认走 Vite 代理即可

3. 若配了 VITE_API_BASE_URL，地址须与后端一致（跨域见下一节）

#### 跨域（CORS）报错

现象： 浏览器控制台出现 CORS、Access-Control-Allow-Origin 相关错误。

说明： 前端（5173）和后端（8000）端口不同，直连时后端须显式允许前端来源。

解决：

- 推荐：不设 VITE_API_BASE_URL，走 Vite 代理（浏览器视为同源，无跨域）

- 直连后端：设 VITE_API_BASE_URL=http://localhost:8000，且 backend/.env 的 CORS_ORIGINS 包含前端地址（默认含 5173）

改 .env 后须重启后端；uvicorn --reload 不会自动重载 .env。

#### 登录 / 鉴权失败

现象： 接口返回 401；登录后立刻跳回登录页；提示需要登录或凭证无效。

说明： 除注册、登录外，请求头须带 Authorization: Bearer <token>。token 过期或被清掉都会 401。

排查：

1. Network 里看失败请求是否带了 Authorization 头

2. 401 时前端会清 localStorage 里的 token，需重新登录

3. 注册/登录失败对照 code：USERNAME_EXISTS（用户名已存在）、INVALID_CREDENTIALS（账号密码错误）

#### 简历上传或解析失败

现象： 提示格式不支持、解析失败、或「简历内容太短」；配置面试时选不了刚传的简历。

说明： 系统从 pdf/docx/txt/md 抽出纯文字（resume_text），后续计划生成都依赖它。扫描版 PDF 可能抽不出足够文字。

排查：

1. 确认格式：pdf、docx、txt、md

2. 扫描版 PDF 建议换可复制版本或 txt/md

3. 有效文字过短会被拒，计划阶段也会再校验

没配大模型时，解析应走规则抽取，不应直接 500。若整站崩溃，查 02-LLM接入与模型调试。

#### pytest 在无 API Key 时失败

现象： 本地没配大模型 Key，跑测试却报错。

说明： 测试通过 conftest 注入假 LLM 客户端，验证模型失败时的规则/模板降级。业务代码不支持 mock Provider。

排查： 单测若仍调真实 API，检查是否绕过了 fixture，或忘记 patch 模型工厂。
