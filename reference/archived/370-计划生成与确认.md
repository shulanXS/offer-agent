# 计划生成与确认

目录路径：实战项目 / AI面试智能体 / 常见问题排查指南 / 计划生成与确认

[原页面](https://acn2lw4rwc26.feishu.cn/wiki/Vx3Uw68eEigm1Pk4QPgcsUn0nNh)

配置页提交后，Planning Agent 生成面试计划（考哪些方向、怎么问等）。这是同步 JSON 接口，不是流式。流程：提交配置 → 预览计划 →（可选）换一版 → 确认 → 才能开始面试。

#### 创建计划失败或一直 loading

现象： 配置页提交后报错或长时间转圈；返回 INTERVIEW_BOOTSTRAP_FAILED（创建失败）或 INTERVIEW_CONFIG_INVALID（配置不合法）。

说明： 生成计划可能调大模型，较慢属正常；前端慢请求最长约等 5 分钟。

排查：

1. 简历：resume_id 须属于当前用户

2. 考察方向：最多 6 个；时长固定 45 分钟

3. 枚举：校招/社招等字段须在允许范围内；JD 注意长度上限

4. 简历文字：过短报 RESUME_TEXT_TOO_SHORT 或 INTERVIEW_INPUT_INVALID，换内容更充实的简历

5. 模型失败时应退回本地岗位模板仍有计划；直接 500 则查 02-LLM 和日志 trace_id

6. 一直 pending 时先看后端日志是否还在跑

#### 计划页空白或字段缺失

现象： 进入计划预览页，考察方向摘要等为空。

排查：

1. POST /api/interviews 是否 200，响应含 session_id、plan_id、candidate_summary（候选人可见摘要）

2. GET /api/interviews/{session_id} 能否拉到详情

3. 未确认前 status 一般为 planning 或 plan_ready

#### 候选人摘要里出现完整面试题

现象： 预览页能看到开场原题、追问话术、评分细则。

说明： 预览只能展示「考什么方向」，不能提前看到「具体怎么问」。完整题目（开场题、追问策略、评分标准等）只在服务端内部计划中，不应下发前端。

排查： 接口是否误返回内部计划字段；前端是否误渲染了内部字段。

#### 重新生成被拒绝

现象： 返回 429 或 INTERVIEW_CONFIG_INVALID；提示次数用尽、策略不对。

说明： 换计划有次数和规则限制。

| 规则 | 说明 |
| --- | --- |
| 次数 | 首版为第 1 版，最多再换 2 次（共 3 版） |
| 确认后 | 点过确认即锁定，不能再换 |
| 无 JD | 不能选「更贴合 JD」类策略 |
| 补充说明 | 仅「换一套计划」可带短说明（约 200 字） |
| 考察方向 | 换版时不能改创建时选的方向 |
| 差异性 | 新版须与上一版有实质区别 |

#### 校招 / 社招计划校验不通过

说明： 计划须覆盖该类型的最低考察面。

- 校招：技术基础、项目/实习/竞赛、问题分析、学习成长（各至少一主题）

- 社招：项目贡献、技术深度、方案/系统设计、故障/工程/业务理解（至少一项）

模型失败时本地岗位模板应能兜底。

#### 确认后无法开始面试

现象： 点「开始面试」报「请先确认并锁定面试计划」，或 404。

排查：

1. 是否成功调用 POST .../plan/confirm

2. 会话详情有 confirmed_plan_id，status 为 plan_confirmed

3. 404：检查 URL 里 session_id 是否正确
