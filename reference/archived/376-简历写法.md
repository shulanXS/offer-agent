### 技术岗

#### 项目介绍

Offer Agent 是一款 AI 模拟面试系统，支持多格式简历解析、岗位与 JD 配置、面试计划预览，以及 45 分钟动态模拟面试。系统将面试流程拆分为规划、面试和评估三个 Agent，通过 ODA（观察—决策—行动）机制实现动态追问与话题切换，并生成基于对话证据的评估报告；同时支持面试进度恢复和跨场次练习结果对比。

技术栈： FastAPI、React、LangGraph、RAG、Milvus Lite、SQLite

#### 个人职责

- 全流程架构与核心开发：负责前后端主链路实现，打通「简历上传解析 → 面试配置 → 计划生成与确认 → 正式模拟面试 → 评估报告与再练」完整流程，覆盖会话管理、额度控制与多格式简历处理（PDF / DOCX / TXT / MD）。

- 多 Agent 系统设计：设计规划、面试、评估三个 Agent 的分工边界，以用户确认后的面试计划作为模块间唯一共享契约；实现计划预览、策略化重新生成与确认锁定，下游 Agent 只读计划，不允许修改。

- LangGraph 动态面试编排：基于 LangGraph 构建每轮回答的状态图，覆盖边界检查、证据提取、结构化决策、话术生成四个核心节点，条件边控制追问、换题、强制结束三条分支。

- 工作记忆与证据驱动评估：每轮调用 LLM 从候选人回答中提取带原话引用的结构化证据，增量合并进本场工作记忆；面试结束后按计划主题汇总证据，用确定性规则推导已验证、部分验证、未验证三态与分数，报告每条评分可展开原话引用。

- RAG 知识库与可靠性工程：接入 Milvus Lite 向量检索按需开关；设计三档降级策略，LLM 调用失败自动切规则降级或模板降级；多模型 API 统一封装，覆盖链路追踪日志与统一错误码。

#### 难点亮点

- 多 Agent 数据一致性：以用户确认后的面试计划为不可变契约，后端硬拒任何修改请求，下游只读不写，从架构层消除状态漂移——而非依赖约定或文档来维系一致。

- ODA 决策与表达分离：面试 Agent 将「下一步做什么」的结构化决策与「怎么说」的话术生成分离，决策可日志追溯、可单测；决策失败时规则降级，行动失败时模板降级，保证 LLM 异常时流程仍可继续。

- 三层记忆与上下文控制：当前主题对话 + 已完成主题摘要控制 Prompt 体积；本场工作记忆结构化积累证据与缺口，驱动追问与评估；跨场次薄弱点仅在不污染当场评分的前提下用于报告对比与练习建议。

- 简历解析链路韧性：采用结构化字段抽取 + 原文留存双方案，提取关键信息用于计划生成、留存全文作兜底；LLM 解析失败自动降级规则抽取，Planning / Interview 另有模板与规则降级，保障主链路可运行。

- 证据驱动可解释评估：评估不重读全场对话即兴打分，而是消费面试过程积累的结构化证据；未充分验证的考察方向不给确定低分，报告支持逐题复盘、JD 要点验证与练习建议闭环。

- AI 回复延迟与体验优化：一轮回复背后多次模型调用，采用生成完整话术后 SSE 分片推送模拟流式输出，配合「思考中」占位与「配置 → 计划确认 → 正式开聊」分阶段设计，降低长等待带来的不确定感。

### 产品岗

#### 项目介绍

Offer Agent 是一款 AI 模拟面试产品，支持简历解析、校招/社招岗位配置、可选 JD、面试计划预览确认、45 分钟动态模拟对话和可解释评估报告，帮助求职用户完成更系统、更贴近真实岗位的面试练习。产品覆盖简历上传 → 面试配置 → 计划预览确认 → 正式作答 → 报告查看与再练完整闭环，支持会话中断后恢复与跨场次进度对比。

#### 个人职责

- 产品从 0 到 1 与迭代升级：负责核心用户路径设计与版本迭代，从早期固定题量脚本式问答，升级为计划驱动、动态追问、证据评分形态；梳理各阶段目标、输入输出与状态边界（计划待确认 / 已锁定 / 对话中 / 评估中）。

- 人机协作（HITL）设计：主导面试计划预览与确认流程，定义重新生成策略与次数上限，平衡用户控制感与防止无限刷题；推动评估报告「每条结论可展开看原话依据」的可解释体验。

- 关键交互体验设计：负责计划页、面试进行页、评估报告与会话列表核心页面体验，推动流式输出占位、计划确认后再消耗额度、评估完成后过渡态等体验细节落地，降低长等待与流程中断带来的用户流失。

- 岗位与 JD 定向能力：定义目标岗位、校招/社招、难度、重点练习方向与可选 JD 的组合输入规则，协同技术侧推进计划生成、JD 要点验证与规划阶段岗位知识库检索，提升练习针对性。

#### 成果

- 用户规模稳步增长：产品累计注册用户超 5 万，日活跃用户约 600，日均新增约 100，用户规模与活跃度持续提升。

- 核心任务完成度高：累计完成模拟面试近 1 万次，核心任务（上传解析 → 确认计划 → 完成面试与评估）成功率达 99.9%，主链路稳定可用。

- 商业模式验证通过：实现业务盈亏平衡，收入可覆盖服务器与人工成本，验证产品模式具备可持续性。

- 迭代后体验显著提升：计划确认 + 动态追问 + 可解释报告上线后，用户满意度由 80% 提升至 90%+，「像真实面试」「评分得讲清楚」相关正向反馈明显增加。
